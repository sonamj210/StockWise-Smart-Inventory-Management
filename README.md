# 📦 StockWise — Smart Inventory and Reorder Management

**StockWise** is a Python-based inventory management web application designed to simplify inventory and sales management for small businesses, especially stationery shops.

It provides a centralized platform to manage products, monitor stock levels, record sales, track transactions, identify low-stock products, and generate useful business reports.

## 🚀 Features

- **Dashboard:** View important inventory and business statistics.
- **Add Product:** Add new products with categories, purchase prices, selling prices, and stock quantities.
- **View Products:** View, search, and filter available products.
- **Stock In:** Update inventory when new products are purchased.
- **Record Sale:** Record customer purchases and automatically update stock.
- **Transaction History:** Maintain records of stock-in and sales transactions.
- **Smart Reorder:** Identify products that reach or fall below their minimum stock level.
- **Reports:** Analyze sales, inventory value, and estimated gross profit.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/StockWise-Smart-Inventory-Management.git
```

### 2. Navigate to the project folder

```bash
cd StockWise-Smart-Inventory-Management
```

### 3. Install dependencies

```bash
pip install streamlit pandas plotly
```

### 4. Run the application

```bash
streamlit run app.py
```

### 5. Open in your browser

```text
http://localhost:8501
```

## 💡 How It Works

1. Add products and their details to the inventory.
2. View and manage available products.
3. Record incoming stock whenever new products are purchased.
4. Record customer sales and automatically reduce stock quantities.
5. Monitor low-stock alerts through Smart Reorder.
6. Analyze inventory and sales performance through Reports.

## 🎯 Project Objective

The main objective of StockWise is to reduce manual inventory management, improve stock tracking accuracy, prevent overselling, and help small business owners make better inventory decisions.
